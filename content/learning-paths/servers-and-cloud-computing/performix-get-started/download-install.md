## Download and install Arm Performix

Performix is free to use and available for all Arm-based server platforms.

1. [Download](https://developer.arm.com/servers-and-cloud-computing/arm-performix) the Arm Performix toolkit for Windows, Mac or Linux on Arm64 or x64 architecture. The toolkit includes both the UI and the CLI. Alternatively you can choose to download the CLI only if you prefer the command-line workflow.
1. Install Arm Performix on your host machine. Follow the detailed steps in the [installation guide](https://learn.arm.com/install-guides/performix) to ensure access is setup correctly.
