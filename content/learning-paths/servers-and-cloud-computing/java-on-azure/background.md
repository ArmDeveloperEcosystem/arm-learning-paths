## Azure Cobalt 200 Arm-based CPU for Linux workloads

Azure Cobalt 200 is Microsoft’s second-generation Arm-based processor, built on Arm Neoverse Compute Subsystems V3 (CSS V3). It supports cloud-native Linux workloads, including Java applications. In this Learning Path, you use a general-purpose **Standard_D4ps_v7** VM with 4 vCPUs.

Learn more in Microsoft’s [introduction to Azure Cobalt 200 virtual machines](https://azure.microsoft.com/en-us/blog/new-azure-cobalt-200-vms-deliver-50-performance-improvement-fully-optimized-for-modern-agentic-ai-workloads/).

## Running Java on Azure Cobalt 200 Arm-based VMs

Java is a mature, object‑oriented language and runtime used to build scalable, secure applications. The Java Virtual Machine (JVM) executes platform‑independent bytecode, enabling *write once, run anywhere* portability across architectures, including Arm64 (AArch64). On Azure Cobalt 200, you use an Arm64 JDK to compile and run your Java code. Application performance depends on the JVM, configuration, and workload.

Learn more with these resources:
- Visit the [OpenJDK website](https://openjdk.org/).
- See the [Java documentation](https://docs.oracle.com/en/java/).
