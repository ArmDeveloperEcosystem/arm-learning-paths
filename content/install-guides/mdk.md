[Arm Keil μVision](https://support.arm.com/tools-and-software/keil-mdk) is the complete software development environment for a range of Arm Cortex-M based microcontroller devices. µVision includes an editor and a debugger, Arm C/C++ compiler, and essential middleware components. It supports more than 13,000 devices and is easy to learn and use.

## What do I need before installing Arm Keil μVision?

You will need a 64-bit x86 Microsoft Windows machine to run Keil μVision.

Full host platform requirements are given in the [System Requirements](https://support.arm.com/tools-and-software/keil-mdk#Editions) section.

## How do I download Arm Keil μVision?

You can download the installer from the [Product Download Hub](https://support.arm.com/downloads/view/MDK000).

Follow the installation instructions provided in the [µVision User's Guide](https://support.arm.com/documentation/101407/latest/About-uVision/Installation).

## How do I set up a license for Arm Keil μVision?

Arm Keil μVision is license managed. Follow the [license setup instructions](https://support.arm.com/documentation/101454/latest/License-Management).

The MDK-Community license is free for non-commercial use and evaluation purposes. Visit [Arm Keil MDK-Community Edition](https://keil.arm.com/mdk-community) for set up instructions.

## How do I get started with Arm Keil μVision? {#start}

To verify everything is installed correctly and to get started with your first project, use an [example project](https://support.arm.com/documentation/101407/latest/Example-Programs).

Once you have copied the example, µVision opens up and you can start working with the project.
